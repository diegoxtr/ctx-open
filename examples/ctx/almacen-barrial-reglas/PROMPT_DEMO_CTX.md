# Prompt para ejecutar la demo con un agente

Copiar este prompt en el agente para reproducir la demo paso a paso.

Nota: si el repositorio esta clonado en otra ruta, reemplazar la ruta del ejemplo antes de enviarlo.

```text
Usa CTX para todo. Trabaja solo dentro de esta carpeta:

C:\sources\ctx-private\examples\ctx\almacen-barrial-reglas

Quiero que hagas la demo paso a paso para ver como se forma el grafo en CTX Viewer.

No hagas todo de una. Primero verifica que no exista .ctx, luego ejecuta ctx init, detenete y decime que deberia verse en el viewer.

Despues, cuando te diga "siguiente", corre el bootstrap sobre .\fuente y volve a detenerte.

Despues revisamos hipotesis, agregamos evidencia desde src/app.js, tomamos una decision, cerramos una conclusion y recien al final hacemos ctx commit.
```
