# 假设评分
如果语言模型及其代理丢失了上下文，这就是你需要的工具。

## 目标

提供一种简单、可操作的方法，按概率、影响和支持度来优先排序假设。

## 当前问题

目前 CTX 存储 `confidence`，但这还不足以判断：

- 哪个假设应优先验证
- 哪个最有潜在价值
- 哪个已经被相反证据削弱

## 建议的 v1 模型

每个假设应按四个维度进行评估：

1. `probability`
   它为真的可能性有多高

2. `impact`
   如果它为真，产品会发生多大变化

3. `evidenceStrength`
   当前有多少结构化证据支持它

4. `costToValidate`
   验证它的成本有多高

## 建议的简单公式

```text
hypothesisScore = (probability * 0.35) + (impact * 0.35) + (evidenceStrength * 0.20) - (costToValidate * 0.10)
```

建议范围：

- `0.0` 到 `1.0`

## 分数解读

- `0.80 - 1.00` 最高优先级
- `0.60 - 0.79` 重要
- `0.40 - 0.59` 次要
- `< 0.40` 低优先级或需要重新定义

## 如何估计每个组成部分

### probability

- 专家直觉
- 既有证据
- 模式重复

### impact

- token 节省
- 时间节省
- 可追溯性提升
- 返工减少

### evidenceStrength

- 证据数量
- 来源质量
- 证据间一致性

### costToValidate

- 时间成本
- 技术复杂度
- 是否需要真实用户
