# CTX - Release 1.0.9

发布日期：

- `2026-04-22`

版本：

- `1.0.9`

## 概要

这个 hotfix 让公共安装流程重新符合预期的用户体验。

普通用户应该从已发布的便携式发行包安装 CTX，而不是从源代码编译整个仓库。

## 变更

- 公共安装 bootstrap 现在默认优先使用已发布的便携式资产。
- README 和安装指南现在明确说明：标准安装流程不应该要求用户安装 .NET 8 SDK。
- 公共 onboarding 文案、截图、示例说明、live-demo 页面以及中文文档已经与当前 state-driven 操作模型保持一致。

## 修复

- 当 `MODE=auto` 时，`install.sh` 和 `install.ps1` 不再把普通用户错误地带入源码构建路径。

## 说明

- `source` 模式仍然保留给开发者和未发布版本验证使用。
- 现在公共安装流程应当理解为：
  - 下载已发布的发行包
  - 安装
  - 暴露 `ctx`
  - 开始操作
