# CTX - Release 1.0.8

Fecha de release: 2026-04-21

Version:

- `1.0.8`

Resumen:

- Patch release estable para CTX 1.0.
- Alinea la experiencia publica de arranque alrededor de un modelo operativo guiado por estado en lugar de un dump plano de comandos.

Highlights:

- `ctx` bare ahora muestra `Current State`, `Meaning`, `Next Command` y una maquina de estados compacta para el entrypoint publico.
- La documentacion publica ahora separa claramente el arranque entre un repositorio CTX existente y un proyecto cognitivo nuevo.
- El loop operativo publico ahora es consistente entre helper prompt, README, docs de CLI, guia de instalacion y protocolo de operacion autonoma.
